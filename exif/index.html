Download clean JPEG ↘

A new copy removes EXIF, GPS, XMP, IPTC, comments, thumbnails and other application blocks. Color profiles and Adobe color-transform information are preserved. A minimal orientation tag is kept when needed to display the image correctly. Image data stays unchanged. Metadata inside retained color profiles, filenames and visible image content may still reveal information.
